## 1. 핵심 요약

중간 프로젝트는 **기말 프로젝트의 기획 단계**이며, 하나의 장면을 중간에서 기말까지 발전시킨다. 현재 장면과 기말까지의 구체적인 계획을 보여 주면 되며, 중간에 장면을 최종 완성할 필요는 없다.

- **중간 평가: 20점**
- **평가 기준일: 2026-11-12(목)**
- **장면: 오브젝트 3개 이상 + 기하 모델링 필수 + 변환 필수 + 선택 요소 1개**
- **①–④ 주제로 인정받는 요소는 직접 작성한 코드여야 한다.**
- **소개글 자체가 기획안**이며, 별도의 기획안은 작성하지 않는다.

## 3. 평가 기준과 점수

교수자가 **소개글, GitHub, 장면 영상**을 보고 채점한다.

| 평가 항목 | 배점 | 공지의 평가 기준 |
|---|---:|---|
| 기법 반영도 | 5점 | 필수와 선택 요소가 인정 기준을 충족하는가 |
| 완성도와 디테일 | 5점 | 지금 단계의 시각적 완성도 |
| 컨셉과 기획 | 5점 | 컨셉이 분명하고, 기말까지의 계획이 구체적인가 |
| 소개글 준비도 | 5점 | 소개글이 양식의 항목을 충실히 갖췄는가 |
| **합계** | **20점** | |

### 코멘트 및 결석 규정

- 코멘트 점수는 **총점에 −2.5 ~ +2.5점**으로 반영된다. 구간별 세부 산정 방식은 이 공지에 없다.
- 11/12 결석 시 공지된 감점: **중간 평가 −5점, 코멘트 −2.5점, 출석 −1.5점**.
- 결석자의 중간 평가는 소개글과 GitHub로 채점한 점수에서 5점을 감점한다.
- 게시자가 결석한 경우 그 소개글에 대한 코멘트는 인정되지 않는다. 영상을 보고 작성한 코멘트도 인정되지 않는다.
- 해당 게시글의 코멘터는 당일 다른 게시자 1명을 골라 코멘트를 작성하고, 댓글 맨 앞에 **[대체]**를 붙인다.

근거: 슬라이드 16–17.

## 4. 장면 구현 및 기법 인정 기준

### 필수 구성

| 구분 | 요구 사항 | 인정 기준·예시 |
|---|---|---|
| 오브젝트 수 | 3개 이상 | 현재 장면의 오브젝트 목록을 소개글에 기재 |
| ① 기하 모델링 | 직접 작성한 코드로 만든 메시 | 그중 **1개는 반복문으로 만든 새로운 형태**여야 함 |
| ④ 변환 | 코드의 행렬로 물체를 움직이거나, 부모–자식으로 묶어 함께 움직이게 함 | 돌면서 떠오르는 물체, 테이블과 그 위의 물건 |
| 선택 요소 | ①–④ 중 요소 1개 추가 | 필수와 같은 주제 중복 가능 |
| 기획 | 기말까지의 계획 | 소개글에 작성 |

### 반복문 메시의 구체적 조건

- 메시 **정점의 일부 이상을 반복문으로 생성**해야 한다. 모든 정점을 반복문으로 만들 필요는 없다.
- 수업에서 다룬 정사면체·육면체 등의 도형이 아닌 **새로운 형태**여야 한다.
- 예: n각기둥, 원뿔, 원기둥, 계단, 나선 계단.
- 직접 정한 몸체 정점과 반복문으로 생성한 원형 지붕을 결합하는 방식도 가능하다.

### 선택 요소: 아래 중 1개 추가

| 주제 | 인정되는 반영 방법 | 공지 예시 |
|---|---|---|
| ① 메시 하나 더 | 앞의 메시와 모양이 다른 메시 추가 | 기둥 메시 + 지붕 메시 |
| ② 래스터화 | 직접 만든 래스터라이저로 그린 그림을 장면 안에 배치 | 정자 벽의 액자 |
| ③ OpenGL 프로그래밍 | GL 클래스로 선이나 삼각형 그리기 | 별자리처럼 이어진 선 |
| ④ 움직임 하나 더 | 다른 물체에 다른 움직임 추가 | 화로 위를 맴도는 불티 |

근거: 슬라이드 9–12, 18–19.

## 7. 소개글에 포함할 기말 계획

다음은 **기말까지 구현할 요구 사항**이다. 중간에는 이를 어떻게 충족할지 소개글에 구체적으로 계획한다.

| 기말 요구 | 계획에 포함할 내용 |
|---|---|
| 오브젝트 총 5개 이상 | 중간 3개에 **2개 이상 추가** |
| 중간 요구 모두 유지 | 기하 모델링·변환·선택 요소 유지 |
| ⑤ 조명 | **직접 작성한 셰이더**로 구현할 조명 |
| ⑥ 곡선과 곡면 | 장면에 반영할 대상과 방법 |
| 확장 단계 URP 기법 | 1개 이상 |
| 심화 선택 콘텐츠 | 1개 이상 |

URP 기법 및 심화 선택 콘텐츠의 구체적인 인정 목록은 이 공지의 중간 프로젝트 안내에 제시되어 있지 않다.

근거: 슬라이드 9, 13–14.

## 9. 혼동 주의: 같은 덱의 별도 과제

아래는 중간 프로젝트 안내와 별개로 덱 마지막에 실린 과제이다.

- **S16 실습 과제 — 11/8까지 (슬라이드 50):** Assets/S16에 관련 에셋을 넣고, 직접 만든 메시 2개 이상에 Mat_S16_MyCoal 또는 복제본을 적용해 숯과 다른 Base Color·Emission Color를 설정한다. 목표 숯, 자신의 셰이더 공, 해당 메시가 함께 보이는 Game view 스크린샷을 준비한다. GitHub push와 사이버캠퍼스 스크린샷 제출이 안내되어 있다. 실습 범위 끝 번호는 원문에 빈칸으로 남아 있다.
- **출석인정과제 — 11/1까지 (슬라이드 51):** Assets/S16_Abs에 S16_MyGlow 셰이더와 Mat_S16_MyGlow 재질을 준비하고, 직접 만든 메시를 파란색으로 빛나게 한다. vert·frag의 역할과 중간 프로젝트 반복문 메시 계획을 3–5문장으로 서술한다. GitHub push와 사이버캠퍼스 스크린샷·서술 제출이 안내되어 있다.

위 별도 과제의 폴더명·제출 방법을 중간 프로젝트의 추가 요구 사항으로 간주하지 않는다.
