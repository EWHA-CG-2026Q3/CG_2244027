픽셀 판정 방식은 CPU에서 캔버스의 각 픽셀 중심이 삼각형 안에 있는지 무게중심 좌표로 검사하고, 내부에 있는 픽셀의 색을 직접 설정한다.
GL immediate mode 방식은 `GL.Begin(GL.TRIANGLES)`와 `GL.Vertex3`로 꼭짓점과 색을 전달하고, 삼각형 내부의 화면 픽셀을 채우는 래스터화는 GPU의 그래픽스 파이프라인에 맡긴다.
나는 픽셀 판정 방식이 삼각형 내부 판정의 원리를 배우거나 픽셀별 처리 규칙을 직접 실험할 때 더 적합하다고 생각한다.
GL immediate mode는 픽셀을 하나씩 계산하는 코드 없이 간단한 도형이나 디버그 표시를 바로 그리는 데 적합하지만, 많은 오브젝트를 그리는 실제 프로젝트에서는 Mesh 기반 렌더링도 함께 고려할 것 같다.
