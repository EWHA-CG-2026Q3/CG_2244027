# 공만 보는 작은 관중들 — 중간 프로젝트 기획안

사용자의 이미지 참고와 아이디어를 바탕으로 작성한 제안안. 구현 완료 상태가 아님.

## 콘셉트

초록색 계단식 관중석에 앉은 작은 동물 인형들이 앞에서 움직이는 공을 바라본다. 몸은 의자에 고정되어 있고 머리만 좌우로 움직인다. 사용자가 화면 위에서 마우스를 움직이면 공이 따라 움직이고, 인형들의 시선도 따라온다.

참고 이미지의 핵심은 짙은 초록색 의자, 크림·갈색·노랑 계열의 인형, 작은 검은 눈, 둥근 얼굴과 짧은 팔다리, 여러 줄로 모인 관중의 구도다. 로고나 개별 캐릭터를 그대로 복제하기보다 직접 디자인한 동물 인형으로 구성한다.

## 중간 구현 범위 제안

- 관중석 3줄 × 4자리, 인형 총 12마리.
- 기본 인형은 곰·토끼·강아지 3종. 공통 몸체 구조에 귀·주둥이·색을 달리한다.
- 하나의 공이 관중석 앞의 제한된 영역에서 움직인다.
- 카메라는 관중석을 정면보다 조금 높은 곳에서 바라보고, 앞쪽에 공이 보이게 배치한다.
- 몸과 머리를 분리한다. 눈·코·귀는 머리에 붙여 함께 회전시킨다.
- 고개는 우선 좌우 회전만 구현하고, 몸과 팔·다리는 고정한다.
- 실제 털 한 올씩 표현하는 작업은 중간 범위에서 제외하고 둥근 형태, 무광 재질, 부드러운 조명으로 인형 느낌을 만든다.

## 마우스 인터랙션

권장 방식은 공 위에 커서를 계속 올리는 방식보다 **Game 화면 안에서 마우스를 움직이면 공이 따라오는 방식**이다. 클릭하거나 드래그하지 않아도 된다.

1. 커서의 화면 위치를 관중석 앞에 설정한 보이지 않는 이동 평면의 위치로 변환한다.
2. 공이 관중석 뒤나 화면 밖으로 가지 않도록 이동 범위를 제한한다.
3. 공은 목표 위치까지 부드럽게 이동한다.
4. 각 인형은 자신의 머리 위치에서 공을 향하는 방향을 계산한다.
5. 목의 좌우 회전을 약 ±40도 정도로 제한하고 천천히 따라가게 한다. 수치는 시연하면서 조정한다.
6. 인형마다 추적 속도를 조금 다르게 해 일제히 움직이는 기계 같은 느낌을 줄인다.

마우스가 화면 밖에 있거나 입력이 없을 때는 공이 자동으로 좌우 왕복하도록 제안한다. 자동 시연은 갤러리 워크와 영상 촬영에도 사용한다. 화면 진입·이탈은 공이 튀지 않도록 부드럽게 연결한다.

## 평가 조건 연결

| 요구 | 구현 계획 | 증빙 |
|---|---|---|
| 오브젝트 3개 이상 | 인형, 관중석 의자, 공 및 추가 인형들 | 장면 전체 이미지와 오브젝트 목록 |
| 필수 ① 기하 모델링 | 반복문으로 단면의 정점을 연결해 둥근 배 모양 인형 몸통 메시 생성 | 직접 작성한 정점·삼각형 생성 코드 |
| 반복문으로 만든 새로운 형태 | 높이별 반지름을 달리한 인형 몸통으로 수업 기본 도형과 다른 형태 구현 | 생성 과정 설명 및 메시 화면 |
| 필수 ④ 변환 | 목을 기준으로 직접 계산한 회전 행렬을 적용해 머리 회전 | 회전 행렬 코드, 머리와 얼굴 부품의 계층 구조 |
| 선택 ① 메시 하나 더 | 몸통과 형태가 다른 둥근 등받이 의자 메시를 별도로 생성 | 의자 메시 생성 코드 |
| 컨셉·기획 | 공을 보는 귀여운 관중이라는 일관된 장면과 기말 확장 계획 | 소개글 |

마우스 인터랙션 자체는 공지에 별도 배점 항목으로 명시되지 않았다. 기본 구체를 배치하거나 LookAt만 호출하는 것으로 기하 모델링·직접 작성한 변환 코드의 증빙을 대신하지 않도록 한다. 실제 인정 여부는 공지 및 교수자 판단을 따른다.

## 기말 확장 계획 제안

- 추가 오브젝트 2개 이상: 작은 점수판, 응원 깃발.
- 직접 작성한 조명 셰이더: 부드러운 인형 표면과 명암 표현.
- 곡선·곡면: 토끼의 처진 귀 또는 강아지 꼬리에 반영.
- URP 기법: 수업에서 인정되는 목록을 확인한 뒤 선택.
- 심화 선택 콘텐츠: 수업 인정 범위를 확인한 뒤 선택. 털 표현을 후보로 검토하되 아직 확정하지 않는다.

## 구현 순서

1. 인형 1마리, 의자 1개, 공 1개로 고개 추적을 먼저 검증한다.
2. 반복문 메시와 직접 계산한 목 회전을 구현해 평가 근거를 확보한다.
3. 마우스 이동과 자동 시연을 연결하고 회전 범위·속도를 조정한다.
4. 곰·토끼·강아지 외형을 만들고 관중석 12자리로 확장한다.
5. 색감·조명·카메라를 다듬고 스크린샷 1–2장과 1분 이내 영상을 준비한다.

평가 및 제출 일정은 [중간과제 평가 기준·제출 항목](./중간과제_평가기준_제출항목.md)을 따른다.
