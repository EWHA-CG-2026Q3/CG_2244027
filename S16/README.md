# S16 셰이더 실습

이 폴더는 독립 Unity 프로젝트입니다. Unity Hub에서 `S16` 폴더를 프로젝트로 추가한 뒤 `Assets/S16/S16_Shader_Practice.unity`를 여세요.

장면에는 이전 과제의 목표 숯 재질을 입힌 숯, 수업의 `S16_MyShader`를 입힌 공, 직접 만든 S03 별과 S04 다이아몬드가 있습니다. 별과 다이아몬드에는 `S16_MyCoal_Finish`를 바탕으로 만든 `S16_MyCoal` 셰이더와 각각 청록색·자홍색의 Base Color 및 Emission Color를 사용했습니다.

교수자 원본 셰이더는 [EWHA_CG_2026Q3의 S16_Shader](https://github.com/EWHA-CG-2026Q3/EWHA_CG_2026Q3/tree/main/Assets/S16_Shader)에서 가져왔습니다. 제출할 이미지는 `Recordings/S16_Shader_GameView.png`이며, 영상이나 스크린샷은 GitHub에 포함하지 않습니다.
