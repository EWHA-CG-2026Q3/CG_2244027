# S08 — Transform order

Unity 6.6.0f1 독립 프로젝트입니다. Unity Hub에서 이 `S08` 폴더를 열고 `Assets/S08/Scenes/S08_TransformOrder.unity`를 실행하세요.

왼쪽 청록색 도형은 `TranslateThenScale`, 오른쪽 분홍색 도형은 `ScaleThenTranslate`입니다. 두 도형 모두 같은 이동값 `(0.9, 0, 0)`과 크기값 `(1.8, 1.8, 1.8)`을 사용합니다. 각 패널 아래의 금색 점은 원점, 색 점은 변환된 도형의 중심을 나타냅니다. Unity 메뉴 `S08 > Verify comparison scene`에서 모드와 계산 결과를 검사할 수 있습니다.

사이버캠퍼스에는 `Assets/S08/Submission`의 Game 뷰 스크린샷과 4문장 서술형을 별도로 제출하세요.
