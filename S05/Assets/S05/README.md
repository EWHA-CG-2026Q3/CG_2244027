# S05 줄무늬와 체스판

Unity Hub에서 저장소 루트가 아닌 `S05` 폴더를 프로젝트로 여세요. Unity 버전은 `6000.6.0f1`입니다.

1. `Scenes/S05_VerticalStripes.unity`를 열고 Play를 누르면 줄무늬가 표시됩니다.
2. Play를 종료하고 `Scenes/S05_Checkerboard.unity`를 열어 Play를 누르면 체스판이 표시됩니다.

원본: https://github.com/Vivi827/EWHA_CG_2026Q3 의 `Assets/S05_MeshRenerer/S05_MyMeshRenderer.cs`

256 × 256 텍스처를 사용하며 무늬 한 칸의 크기는 16 텍셀입니다. Inspector의 Pattern으로 두 함수를 선택할 수 있습니다.

`Screenshots`의 두 PNG와 `Answer.md`의 4문장을 사이버캠퍼스에 별도로 제출하세요. GitHub push와 사이버캠퍼스 제출은 별개의 절차입니다.
