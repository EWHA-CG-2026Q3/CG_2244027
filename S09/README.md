# S09 — Diamond shear

Unity 6.6.0f1 독립 프로젝트입니다. Unity Hub에서 이 `S09` 폴더를 열고 `Assets/S09/Scenes/S09_DiamondShear.unity`를 여세요.

학번 `2244027`의 끝자리 7을 사용해 `k=(7+1)/5=1.6`으로 설정했습니다. 왼쪽은 +1.6, 오른쪽은 -1.6으로 기울였으며, 반투명한 원본 다이아몬드를 변형본과 동일한 위치에 두었습니다. 원본에는 `DiamondMesh`만, 변형본에는 `DiamondMesh`와 `S09_ShearDiamond`를 붙였습니다.

Unity 메뉴 `S09 > Verify shear scene`에서 행렬과 정점 결과를 검사하고, `S09 > Log both top vertices`에서 두 꼭대기 정점의 `Debug.Log`를 확인할 수 있습니다. 사이버캠퍼스에는 `Assets/S09/Submission`의 스크린샷 3장과 서술형을 별도로 제출하세요.
