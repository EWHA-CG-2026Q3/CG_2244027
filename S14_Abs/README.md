# S14 출석인정: 랜턴과 불티 정자 장면

이 폴더는 독립된 Unity 프로젝트입니다. Unity Hub에서 `S14_Abs`를 프로젝트로 추가하고 `Assets/S14_Abs/S14_Abs_Landscape.unity`를 여세요. S13의 정자 장면을 이어받되 원본 프로젝트는 변경하지 않았습니다. 외부 Pavilion 에셋은 `Assets/ThirdParty/Pavilion`에 있습니다.

정자 내부 탁자에는 금속 텍스처 몸체, 발광 구체와 Point Light를 가진 랜턴이 있습니다. 랜턴 주변에는 연기와 다른 작은 불티 파티클이 올라가며 Global Volume Bloom이 빛을 퍼뜨립니다. S13 장면을 기반으로 하며, 별도 S14 본과제 프로젝트와는 서로 영향을 주지 않습니다.

`SceneWalker`로 Play 모드에서 WASD 이동과 마우스 회전을 할 수 있습니다. Unity 메뉴 `S14 Abs > Preview ShotCamera`로 정자 내부 스크린샷 구도를 볼 수 있고, `Preview Walker Camera`로 걷기 화면에 돌아옵니다. `Record 40-second Game view walk`는 야외에서 내부로 이동하는 40초 영상을 `Recordings`에 저장합니다. `Recordings`는 GitHub 업로드에서 제외되므로 영상과 스크린샷은 사이버캠퍼스에 별도로 제출해야 합니다.
