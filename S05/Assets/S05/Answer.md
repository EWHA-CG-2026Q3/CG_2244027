# S05 서술형

텍셀은 텍스처를 구성하는 색상 데이터의 최소 단위이고, 스크린 픽셀은 화면에 최종 이미지가 표시되는 최소 단위이다.
텍스처를 화면에 확대하거나 축소하면 하나의 텍셀이 여러 스크린 픽셀에 표시되거나 여러 텍셀이 하나의 스크린 픽셀 색에 영향을 줄 수 있으므로, 둘이 항상 일대일로 대응하지는 않는다.
래스터화는 삼각형 등의 도형이 화면의 어느 픽셀을 덮는지 판정하여 픽셀 단위의 이미지로 바꾸는 과정이다.
오늘은 2차원 캔버스의 가로 좌표 x와 세로 좌표 y만으로 줄무늬와 체스판의 색을 정했으며, 물체 사이의 깊이나 앞뒤 관계를 계산할 필요가 없어서 z를 사용하지 않았다.
